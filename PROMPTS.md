# AI Prompts and Development Assistance

## Overview
AI-assisted guidance was used during the development of TrustVault to support implementation, debugging, documentation, and deployment.

## Prompt 1: Project Architecture
"Help me design a secure document management web application using Node.js, Express.js, MySQL, and a JavaScript frontend. Include authentication, document management, sharing permissions, and audit logging."

## Prompt 2: Authentication
"Help implement user registration and login using bcrypt password hashing, JWT authentication, and environment-based configuration."

## Prompt 3: Document Management
"Help implement APIs for uploading, downloading, editing, and deleting documents, with ownership checks and permission validation."

## Prompt 4: Document Sharing
"Help design document-sharing functionality with view and edit permissions, including checks to prevent unauthorized access."

## Prompt 5: Company Isolation
"Help implement company-based data isolation so users cannot access documents or audit records outside their authorized company."

## Prompt 6: Audit Logging
"Help implement audit logs for document activities, permission changes, and denied access attempts."

## Prompt 7: Database Connectivity
"Help configure a MySQL connection using environment variables and SSL for a cloud-hosted database."

## Prompt 8: Debugging and Testing
"Help diagnose application errors, verify API endpoints, and test authentication, document operations, sharing, and access controls."

## Prompt 9: Deployment
"Help deploy an Express.js application to Render and connect it to a cloud-hosted MySQL database."

## Prompt 10: Documentation
"Help prepare a README, security threat model, and project documentation for a secure document management application."

## Responsible Use
AI assistance was used as a development aid. The resulting code, configurations, and security controls should be reviewed and tested by the project author before production use.
